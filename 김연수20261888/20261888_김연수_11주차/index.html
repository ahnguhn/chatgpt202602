랜덤 뽑기

발표자, 청소 당번, 오늘의 메뉴까지. 후보를 등록하고 필요한 수만큼 뽑아보세요.

① 후보 등록② 참여 후보 선택③ 뽑을 인원 설정④ 결과 확인

① 후보 등록

한 번에 하나씩 입력하세요. 동명이인은 김민수(1), 김민수(2)처럼 구분해주세요.

② 참여 후보 선택

전체 후보 0 참여 중 0

체크한 후보만 추첨에 참여합니다. 새 후보는 참여 상태로 등록됩니다.

후보를 먼저 등록해주세요.

    ③ 뽑을 인원 설정

    참여 후보 수 이하의 정수를 입력하세요. 한 번의 추첨에서 중복으로 뽑히지 않습니다.

    다시 뽑기는 이전 당첨자도 포함한 현재 참여 후보 전체를 대상으로 합니다.

    ④ 결과 확인

    아직 추첨 전입니다.

    후보와 인원을 설정한 후 ‘랜덤 뽑기’를 눌러주세요.

      결과의 번호는 순위가 아니라 추첨 순서입니다.

      처음부터 새로 시작하려면
      전체 내용을 초기화하세요.

      입력 내용은 저장되지 않으며 새로고침하면 사라집니다. 외부 연결 없이 이 파일 안에서만 작동합니다.
