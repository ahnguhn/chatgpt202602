이름: 김준현

1. 실행
압축을 풀고 프로그램 폴더의 index.html을 최신 브라우저에서 엽니다.
외부 라이브러리, 설치, 인터넷 연결, 별도 서버가 필요하지 않습니다.
모바일 파일 앱의 단순 미리보기 대신 JavaScript 실행을 지원하는 브라우저로 열어주세요.

2. 게임 규칙
60초 안에 별 25개를 모으면 성공합니다.
시작 체력은 3이며 운석 충돌마다 1 감소합니다.
체력 0 또는 시간 초과 시 실패합니다.
놓친 별에는 감점이 없습니다.
파란 보호막은 운석 충돌을 1회 방어합니다. 보호막은 중첩되지 않습니다.
운석 충돌 후 1.25초 동안 추가 피해를 받지 않습니다.
별 10개, 20개 수집 시 난이도가 올라갑니다.

3. 조작
PC: 방향키 ← → 또는 A / D
모바일: 게임 영역 터치 드래그 또는 하단 좌우 버튼
일시정지: P, Esc, 멈춤 버튼
탭 또는 창 이탈: 자동 일시정지
종료 후 다시 시작 버튼: 모든 상태 초기화

4. 파일 구성
index.html: 게임 전체 (HTML, CSS, JavaScript)
README.txt: 실행 안내
screenshots/desktop_start.png: 최종 시작 화면
screenshots/desktop_play.png: PC 진행 화면
screenshots/mobile_play.png: 모바일 폭 390px 진행 화면
우주선·별·운석·보호막은 Canvas로 직접 그립니다.
외부 이미지 파일을 불러오지 않으므로 실행용 assets 폴더는 필요하지 않습니다.
screenshots는 과정기록 증빙용이며 실행 중에는 불러오지 않습니다.
