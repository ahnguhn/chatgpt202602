프로그램: 컬러 매치 챌린지

[실행]
압축 해제 후 index.html을 브라우저에서 연다.
서버·설치·인터넷·외부 이미지가 필요 없다.
외부 라이브러리와 저장 기능은 앱에 사용하지 않았다.

[게임 규칙]
글자의 뜻이 아니라 글자에 칠해진 색을 선택한다.
40초 이내 정답 12개면 성공.
생명 3개로 시작하여 오답마다 1개 감소.
생명 0 또는 시간 0이면 실패.
클릭·터치 또는 숫자 1~4. 일시정지/계속하기는 버튼 또는 P.
응답 후 180ms 동안 중복 입력을 막는다. 키를 길게 눌렀을 때의 반복 이벤트도 무시한다.
일시정지 중에는 문제를 가리고 시간과 응답을 멈춘다.
다른 탭으로 전환하면 자동 일시정지하며, 돌아와 계속하기를 눌러야 한다.
결과 화면의 다시 시작 버튼으로 점수·생명·시간을 초기화한다.
글자 색을 구분할 수 있는 색각 환경을 전제로 한다.

[구성]
index.html: 최종 게임
evidence/initial_v1.html: 실제 최초 구현본
evidence/initial_findings.json: 첫 테스트의 관찰값
evidence/prompts.txt: 제작·수정 사양 정리본 (별도 대화 원문 아님)
evidence/test_results.json: 실제 자동화 테스트 32개 결과
evidence/*.png: 실제 브라우저 화면
run_tests.py: 최종 검증용 (Python, Playwright, Chromium 필요)
test_initial.py: 최초 버전 확인용 (같은 개발 도구 필요)

[검증 범위]
Chromium headless에서 HTML 직접 로드(set_content).
타이머 테스트는 제어 가능한 브라우저 시계를 사용했다.
모바일은 뷰포트/터치 모사이며 실물 기기 테스트가 아니다.
file:// 직접 열기와 다른 브라우저는 이 제작 환경에서 확인하지 않았다.
Playwright는 개발 검증 도구로만 사용했으며 앱의 의존성이 아니다.
테스트 실행 시 Chromium 경로는 환경에 맞게 조정한다.

[제출 전]
A 또는 B 중 하나를 선택하여 해당 ZIP과 과정기록 PDF를 제출한다.
index.html을 직접 열고 시작→종료→다시 시작을 확인한다.
AI의 도움으로 제작한 문서의 성찰 예시는 자신의 실제 경험에 맞게 수정한다.
