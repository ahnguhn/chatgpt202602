11주차 선택 A — 하이볼 노트 (과제 제출용)
================================================

실행
1. ZIP 압축을 푼 뒤 highball_note 폴더를 엽니다.
2. index.html을 Chrome 또는 Edge 등 최신 브라우저로 엽니다.
3. 재료 이름, 용량(mL), 도수(%)를 입력하거나 재료 도감·레시피를 선택합니다.
4. 현재 남아 있는 얼음(g), 이미 녹은 물(mL), 30분당 녹는 양(g)을 입력합니다.
5. 현재 도수와 30분 단위 시간표를 비교합니다.

기능
- 여러 재료의 도수 계산, 재료 추가·입력 수정·개별 삭제·재료 비우기
- 재료 도감 28종: 검색·분류·계산기에 추가, 가니시 사용 팁
- 레시피 8개: 검색·종류 필터·확인 후 현재 배합 교체
- 얼음 희석 시나리오: 0~360분, 30분 단위, 시간 슬라이더
- 전체 초기화: 재료·얼음·시간·검색·필터를 기본값으로 복구
- 빈 재료 이름, 빈 숫자, 음수, 범위 초과, 액체량 0mL 안내

과제 기술 조건
HTML·CSS·JavaScript가 모두 index.html 안에 있습니다.
외부 라이브러리, CDN, 원격 이미지, 웹폰트, 서버, 설치가 필요 없습니다.
별도 이미지 없이 HTML과 CSS로 화면을 구성하여 실행용 assets 파일이 없습니다.
사용자가 누르는 참고 출처 링크는 인터넷이 있어야 열립니다.
자동 외부 요청은 없으며, 링크를 열지 않아도 계산·도감·레시피는 동작합니다.

저장 기능 없음
과제 지시문에 따라 첨부 원본의 자동 저장·JSON 백업·복원·결과 복사 기능을 제거했습니다.
입력은 페이지 실행 중 메모리에만 있고 페이지를 다시 열거나 새로고침하면 기본값으로 돌아갑니다.
이 제출용 버전은 이전 웹앱의 브라우저 기록을 읽거나 수정하지 않습니다.
Windows EXE는 웹 제출 과제 형식과 달라 이 제출물에 포함하지 않습니다.

계산 원리
A = 각 재료의 [용량 × 도수 / 100] 합
V = 재료 부피 합 + 이미 녹은 물
W(t) = min(현재 얼음 g, 30분당 녹는 g × t / 30)
도수(%) = 100 × A / (V + W(t))
얼음 1g을 물 약 1mL로 단순화합니다.
10·25·45g/30분 프리셋은 실험값이 아닌 비교용 설정입니다.
온도·잔·얼음 크기·교반·음용·증발·부피 수축을 자동 반영하지 않습니다.
제품 도수는 예시 또는 원본 참고 정보이므로 실제 라벨을 우선하세요.
도수가 낮아져도 알코올 총량은 그대로입니다. 성인용 참고 도구이며 안전·운전 판단용이 아닙니다.

검증
2026-11-12, Linux headless Chromium 144.0.7559.96에서 31건 통과.
실행 환경의 탐색 정책 때문에 file:// 및 localhost를 직접 열지 못했습니다.
따라서 동일 HTML을 page.setContent로 브라우저 문서에 주입해 기능·반응형·터치를 확인했습니다.
PC 1440×1000, 모바일 크기 390×844; 모바일은 화면·터치 에뮬레이션입니다.
실제 Windows Chrome/Edge 파일 열기와 실제 스마트폰은 제출 전에 사용자가 최종 확인해야 합니다.
