과제온 · 대학생 과제 우선순위 플래너
11주차 바이브코딩 선택과제 / A유형
학번: 20261454
이름: 유지연

[실행]
1. ZIP 파일을 압축 해제합니다.
2. 최상위 폴더의 index.html을 Chrome 또는 Edge 등 브라우저로 엽니다.
3. 기준일을 확인하고 과제를 입력한 후 ‘과제 추가하기’를 누릅니다.
4. 빈 목록에서 ‘예시 불러오기’를 누르면 예시 4개를 확인할 수 있습니다.

[주요 기능]
과제 추가/수정/삭제/초기화, 완료 전환, 우선순위 계산,
상태 필터, 3가지 정렬, 통계 및 완료율, 모바일 반응형 화면.
점수 = 중요도 × 20 + 긴급도. 자세한 규칙은 화면 하단에 있습니다.

[데이터]
과제 데이터는 현재 문서의 메모리에만 있습니다.
새로고침/탭 닫기/새 문서 실행 시 사라지며 저장·복구하지 않습니다.
외부 라이브러리·외부 이미지·서버 API·설치 과정이 없습니다.
실행에 필요한 파일은 index.html 하나입니다.

[폴더]
index.html                 최종 실행 파일
README.txt                 실행 방법
과정자료/최초버전_v1.html   수정 전 버전(최종본 아님)
과정자료/프롬프트.txt       최초 및 수정 작업 지시
과정자료/테스트결과.json    44개 자동 테스트 상세
과정자료/화면/             실제 브라우저 실행 캡처

[검증 범위]
Chromium + Playwright에서 44개 테스트 통과. 기준일 2026-11-12.
HTML 문자열을 새 브라우저 문서에 직접 로드(set_content)하여 테스트했습니다.
로컬 파일 더블클릭, 실물 휴대폰, Safari/Firefox 실행은 확인하지 않았습니다.
320/360/390/768/1440px 화면 너비와 390px UI 조작을 확인했습니다.

[제출 전]
본인 PC에서 index.html을 열어 최종 실행을 확인하세요.
과정기록 PDF의 성찰 초안은 직접 사용한 경험에 맞춰 확인·수정하세요.
