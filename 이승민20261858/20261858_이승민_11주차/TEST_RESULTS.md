# 최종 테스트 결과

테스트 환경: Chromium 헤드리스, 자동 실행. 실제 기기 테스트가 아닙니다.
HTML 내용을 브라우저에 로드해 시험했습니다. 로컬 파일 직접 열기는 실행 환경 제한으로 미검증입니다.
일반 게임 흐름은 가속 시뮬레이션, 개별 충돌·장거리 분기는 값 지정으로 분리 검증했습니다.

| 항목 | 결과 및 방법 |
|---|---|
| 시작 → 진행 → 종료 → 재시작 | 통과 — 일반 생성·충돌 규칙을 1/60초 간격으로 가속 실행, 임의 충돌 주입 없이 종료 확인 |
| 방향키와 카빙 | 통과 — 방향키 입력에 따른 위치·기울기 변화 확인 |
| 좌우 경계 | 통과 — 지속 입력해도 플레이어의 위치가 경계를 넘지 않음 |
| 좌우 동시 입력 | 통과 — 중립 처리 확인 |
| 생명 감소 | 통과 — 충돌 위치를 지정해 생명 3 → 2 확인 |
| 무적 처리 | 통과 — 무적 중 장애물 추가 시 생명 2 유지 |
| 무한 모드 | 통과 — 거리 1,500m 지정 후 진행·장애물 생성 유지 |
| 장애물 배치 | 통과 — 1,000회 생성에서 2~3개, 예약한 인접 2칸에 배치 없음 |
| 일시정지·계속 | 통과 — 정지 중 거리 유지, 재개 후 진행 |
| 빠른 반복 입력 | 통과 — 일시정지/계속 4회 반복 후 정상 상태 |
| 창 비활성화 | 통과 — blur 이벤트 후 자동 일시정지 |
| 모바일 터치 | 통과 — 브라우저 터치 에뮬레이션으로 이동 및 터치 종료 확인 |
| 화면 크기 변경 | 통과 — 4개 크기에서 가로 넘침 없음, 플레이어 경계 유지 |
| 투명 PNG | 통과 — 3개 로드 및 모서리 알파값 0 확인 |
| 상대 경로·구조 | 통과 — index.html과 assets/*.png 존재 및 경로 일치 |
| JavaScript | 통과 — node --check 및 브라우저 pageerror 없음 |

미검증: 실제 스마트폰, Safari, 장시간 플레이의 난이도 균형.
