[실행]
ZIP을 모두 압축 해제한 다음 이 폴더의 index.html을 브라우저로 여세요.
게임 실행에는 인터넷, 서버, 별도 설치, 외부 라이브러리가 필요하지 않습니다.
채팅 앱/학습관리시스템의 미리보기에서는 JavaScript가 차단될 수 있으므로
파일을 내려받아 Chrome 또는 Edge 등 브라우저로 열어 주세요.

[게임 규칙]
- 끝없이 슬로프를 내려가며 나무와 바위를 피하고 이동 거리와 생존 시간을 늘립니다.
- 생명은 3개입니다. 충돌마다 1개 감소하고 생명 0이면 게임이 끝납니다.
- 충돌 후 1.6초간 무적입니다.
- 한 줄에 장애물이 2~3개 나오고 거리가 증가하면 속도와 등장 빈도가 높아집니다.
- 6개 위치 중 인접한 2개 위치는 비워둡니다. 모든 상황의 회피 가능성을 보장하는 것은 아닙니다.
- 무한 모드이므로 별도의 완주/승리 종료는 없습니다.
- 화면에 거리, 시간, 생명, 난이도(LV.1~5)가 표시됩니다.

[조작]
PC: ← / → 또는 A / D를 누르고 있기
모바일: 아래 좌우 버튼을 누르고 있기
일시정지/계속: 상단 버튼, Space, P, Esc
게임 종료 후: 다시 도전하기
탭/창이 비활성화되면 자동으로 일시정지합니다.

[이미지]
assets/skier.png : 뒷모습 스키어
assets/tree.png  : 눈 덮인 나무
assets/rock.png  : 눈 덮인 바위
사용자가 첨부한 JPG에서 외부 배경과 가로 잔상을 윤곽 마스크로 제거한 실제 투명 PNG입니다.
원본 그림 내부를 유지했으며 일부 미세한 경계 흔적이 남을 수 있습니다.
상대 경로 PNG를 먼저 로드하고, 로드 실패 시 HTML 내장 PNG를 사용합니다.
파일 확장자만 바꾼 이미지가 아닙니다.

[증빙]

test_results.json: 자동 기능 테스트의 상세 결과

최종 제출물에는 별도 과정기록 PDF가 함께 제공됩니다.

[검증 범위]
제한된 실행 환경 때문에 로컬 파일 URL 직접 열기는 검증하지 못했습니다.
동일 HTML 내용을 Chromium에 로드해 키보드/브라우저 터치/충돌/무적/종료/재시작을 시험하고,
assets 상대 경로 파일의 존재를 별도 확인했습니다.
화면 크기 320×568, 390×844, 768×1024, 1440×900을 확인했습니다.
실제 스마트폰 하드웨어, Safari, 장시간 난이도 균형은 추가 확인이 필요합니다.
