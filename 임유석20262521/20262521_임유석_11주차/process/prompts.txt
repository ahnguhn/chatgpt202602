제작 요구 프롬프트 정리본

대학생이 과제를 정리하는 ‘과제 한눈에’ 웹앱을 만들어 줘. HTML·CSS·JavaScript를 한 개의 index.html에 넣고 외부 라이브러리, 서버, 저장 기능은 사용하지 마.
과제 이름(앞뒤 공백 제거 후 1~50자), 예상 시간(1~600분 정수), 중요도(보통/높음)를 입력받아 과제를 추가해 줘. 빈 값, 공백만 있는 제목, 잘못된 시간은 등록하지 말고 입력란 근처에 이유를 알려 줘.
목록에는 제목·시간·중요도를 표시하고, 중요도가 높으면 먼저 배치해 줘. 중요도가 같으면 등록 순서를 유지해 줘. 완료 전환, 완료 취소, 개별 삭제와 확인창이 있는 전체 초기화를 넣어 줘.
전체·진행 중·완료 필터를 제공하고 전체 개수, 완료율, 미완료 과제의 예상 시간 합계를 표시해 줘. 완료율은 완료 개수/전체 개수×100을 반올림하며, 전체가 0이면 0%로 표시해 줘. 통계는 필터에 관계없이 전체 목록 기준으로 계산해 줘.
PC는 입력과 목록을 나란히 배치하고 모바일은 세로로 배치해 줘. 파란색 계열의 단순한 화면, 연결된 입력 라벨, 키보드로 누를 수 있는 버튼을 사용해 줘. 화면에 20262521 임유석을 표시하고 새로고침하면 데이터가 사라진다는 점을 안내해 줘.

수정 요구 프롬프트 정리본

초기 버전에서 예상 시간을 1.5로 입력하면 과제가 등록돼. 재현 절차는 제목에 ‘소수 입력 확인’, 시간에 ‘1.5’를 넣고 추가하기를 누르는 거야. 정수만 받기로 했으므로 소수는 등록하지 않고 ‘예상 시간은 1~600 사이의 정수로 입력해 주세요.’라고 안내해야 해.
HTML의 step=1만 믿지 말고 JavaScript에서 Number.isInteger(minutes)로 정수 여부를 검사해 줘. 빈 값·0·음수·601도 막고 1과 600은 허용해 줘. 기존 디자인, 중요도 정렬, 완료 전환, 필터, 통계와 초기화 기능은 유지해 줘.
