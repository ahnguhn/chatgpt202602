감스트 샷건 게임 / 11주차 선택 B

실행 방법
1. ZIP을 먼저 압축 해제합니다.
2. gamst_game 폴더 안의 index.html을 Chrome 또는 Edge에서 엽니다.
3. assets 폴더와 index.html의 상대 위치를 그대로 유지합니다.
서버, 외부 라이브러리, 설치, 로그인은 필요하지 않습니다.

구성
gamst_game/
  index.html
  assets/
    face.jpg
  README.txt

규칙
- 30초 동안 2,500점 이상이면 목표 달성, 미만이면 목표 미달.
- Space / 샷건 버튼: 일반 타격. 초록 구간에서는 PERFECT.
- F / 분노 폭발 버튼: 분노 100%일 때 특수 공격.
- P / 일시정지 버튼: 정지 또는 이어하기.
- 키보드 파괴 시 500점 추가, 다음 키보드 체력 증가.
- 초기화는 현재 판을 초기화. 이번 실행 최고 점수는 페이지를 새로 열 때 초기화.
- PC 키보드 및 버튼, 모바일 터치 버튼 지원.
- 실제 키보드는 가볍게 눌러 주세요.

이미지

사진은 외부 서버로 전송되지 않습니다.
비공식 팬 창작 학습용 게임이며 실제 인물의 후원·공인을 의미하지 않습니다.
